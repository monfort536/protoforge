# Generated image assets

Created with the built-in `image_gen` tool under the imagegen skill. The assets are illustrative, not evidence of a real ProtoForge facility or completed customer job. All final project assets are saved under `assets/images/optimized/`, with `-sm.webp` variants for smaller screens. Originals from the tool were left in its generated-images directory; the website never references that directory.
